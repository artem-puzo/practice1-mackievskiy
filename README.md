## Описание проекта
Адаптируемая информационная веб-страница, разработанная на чистых HTML5 и CSS3. Содержимое сформировано на основе исходных данных из dataset (`content.csv`, `navigation.json`).

---

## Примененные технологии и CSS-приемы
* **Семантическая разметка HTML5:** Использование тегов `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<table>`, `<form>`, `<footer>`.
* **Доступность (Accessibility / A11y):** Связка элементов `<label>` с `<input>` через `id`, атрибуты `aria-label`, альтернативные тексты `alt` для векторных SVG-изображений.
* **Верстка и Layout:** Использование **Flexbox** (`display: flex`, `flex-wrap: wrap`, `gap`) для адаптивной сетки карточек и шапки сайта.
* **Блочная модель (Box Model):** Явный сброс параметров через `box-sizing: border-box`.
* **Интерактивность:** Оформление состояний `:hover` и `:focus` для ссылок, кнопок и полей ввода.
* **Адаптивность:** Медиазапрос `@media (max-width: 720px)` для перестройки интерфейса под мобильные экраны.
* **Валидация HTML5:** Атрибуты `required`, `minlength`, `maxlength`, `min`, `max`, `step`.

## Использованные файлы dataset
* `dataset/navigation.json` — структура пунктов меню и идентификаторы разделов.
* `dataset/content.csv` — данные для заполнения 6 карточек и сводной таблицы.
* `dataset/assets/logo.svg` — логотип в шапке сайта.
* `dataset/assets/cover.svg` — обложка в главном баннере.
